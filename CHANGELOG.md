## 1.00 — 2026-10-23

- Arabic and English interface, a saved language preference, and automatic RTL/LTR layout. User-entered text and filenames stay unchanged.
- Localized Windows caption, export dialogs, notifications, history and status messages.
- Custom animated backgrounds, optional original colors, cover artwork and logo upload.
- Image preparation in a worker; fixed file-picker focus shifting the workspace and preventing scrolling to the top.
- True waveforms, entrance/exit effects, custom export settings, offline native GPU export and export history.
- Lightweight public Windows build uses separately installed FFmpeg, discovered beside the app, on PATH, through `QASEEDA_FFMPEG`, or selected on first export.
- Release candidate workflow with draft releases, portable ZIP, source ZIP and SHA-256 checksums; bilingual issue forms and contribution templates.
- Clean GitHub source package, portable Windows build scripts, pinned WebView2 restore, CI checks, MIT source license and separate third-party notices.

Displayed product version: **1.00**. Standard package/assembly version: **1.0.0**.
