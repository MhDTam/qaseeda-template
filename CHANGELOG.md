# Changelog

## 1.01 — 2026-10-24

First public release of Qaseeda Template under the MIT license, with copyright attributed to `MhDTam`.

- Arabic and English interface with saved language preference and automatic RTL/LTR layout.
- Custom artwork and animated backgrounds, true audio waveforms, optional logos and entrance/exit effects.
- Local Windows MP4/WebM export up to 4K, custom export settings and export history.
- Portable Windows package that uses a separately installed FFmpeg executable.

Displayed product version: **1.01**. Standard package/assembly version: **1.0.1**.
