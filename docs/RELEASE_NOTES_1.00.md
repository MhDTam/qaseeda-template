# قالب قصيدة · Qaseeda Template 1.00

أول إصدار مفتوح المصدر. واجهة عربية وإنجليزية، صور وخلفيات مخصصة مع إضاءة متحركة، موجات صوتية حقيقية، لوغو، وحركات دخول وخروج. تصدير حتى 4K مع سجل وتنبيه عند الاكتمال، وتسريع NVIDIA عند توفره.

**Windows:** نزّل ملف ZIP وفك ضغطه ثم شغّل `QaseedaTemplate-1.00.exe`. يتطلب Windows 10/11 x64 وWebView2 Runtime. ثبّت FFmpeg بشكل منفصل؛ ضعه بجوار التطبيق أو اختر `ffmpeg.exe` عند أول تصدير. التطبيق يحفظ مساره للمرة القادمة. لا توجد قصيدة افتراضية أو خطوط تجارية مضمّنة.

First open-source release: Arabic/English UI, custom artwork and animated backgrounds, real audio waveforms, logos, entrance/exit animations, exports up to 4K, completion notifications and export history. NVIDIA acceleration is used when supported.

**Windows:** extract the ZIP and run `QaseedaTemplate-1.00.exe`. Requires Windows 10/11 x64 and Microsoft WebView2 Runtime. Install FFmpeg separately: place `ffmpeg.exe` beside the app, put it on PATH, set `QASEEDA_FFMPEG`, or select it on the first export. The chosen path is saved. No default recording or proprietary embedded font is included.

The executable is unsigned. Browser recording speed and formats depend on browser support; native Windows export uses hardware acceleration where available. Background lighting animates an image rather than generating object movement.

Verify downloads against `SHA256SUMS-1.00.txt`. Source code and project artwork are MIT licensed; third-party notices are included. FFmpeg and WebView2 Runtime are separate installations with their own terms.
