# Qaseeda Template · قالب قصيدة 1.00

First public release under the MIT license, with copyright attributed to **MhDTam**. Includes an Arabic/English audio visualizer, custom artwork and animated backgrounds, and Windows video export.

**Windows:** run `QaseedaTemplate-1.00-Setup.exe` on Windows 10/11 x64. This small online installer installs WebView2 Runtime from Microsoft if missing and optionally downloads a SHA-256 verified FFmpeg build from Gyan for video export. Internet is needed when prerequisites are missing. You can deselect FFmpeg and supply your own copy. The portable ZIP remains available; extract it and run `QaseedaTemplate-1.00.exe`, then install/select FFmpeg separately. No personal recording, proprietary embedded font, or FFmpeg binary is hosted in this release.

Verify downloads against `SHA256SUMS-1.00.txt`. The original source code and project artwork use the MIT license; bundled third-party notices retain their own terms. The executable is not code-signed.
