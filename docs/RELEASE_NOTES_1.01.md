# Qaseeda Template · قالب قصيدة 1.01

This release corrects the MIT copyright attribution to **MhDTam** in the public source and Windows package. The audio visualizer and video export features from 1.00 remain available.

**Windows:** extract `QaseedaTemplate-1.01-windows-x64.zip` and run `QaseedaTemplate-1.01.exe`. Windows 10/11 x64 and Microsoft WebView2 Runtime are required. Install FFmpeg separately: place `ffmpeg.exe` beside the app, put it on PATH, set `QASEEDA_FFMPEG`, or select it on the first export. No personal recording, proprietary embedded font, or FFmpeg binary is included.

Verify downloads against `SHA256SUMS-1.01.txt`. The original source code and project artwork use the MIT license; bundled third-party notices retain their own terms. The executable is not code-signed.
